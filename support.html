How do I add a tool?

Add an HTML tool you have made or received, or start with a template from Settings > Ideas and templates. Tap +, enter a name, choose an appearance, and select a file or paste HTML. Settings > How to use Doodad includes copyable instructions for making tools that work in Doodad and a working HTML example.

Why isn't my tool saving?

Its HTML needs to follow the saving instructions available in Settings > How to use Doodad. The Writing your own HTML? section explains how to restore and save data, with a working example. A tool's own save error should let you retry. Avoid removing the app to troubleshoot; that removes its local library.

How do I update a tool?

Open Edit from the viewer or Options. Copy includes the current HTML and instructions to keep your saved data compatible. Paste the updated HTML, or choose a file, then Save. Incoming files can also update an existing Doodad's code. Existing data is kept; new code must remain compatible with it.

How do I back up or share?

Choose Share from a card's Options menu. Turn on Include saved data to keep your progress and all stored photos, videos, and audio, then choose Save to Files or a recipient. Each .doodad copy is independent. There is no automatic backup or sync. Copies with audio need a version of Doodad that supports audio storage.

How do I record audio?

The tool must support Doodad's recording instructions. Its recording action opens a native recorder. Tap Record there to allow microphone access and start recording, then Stop and Save recording. Closing the recorder lets you discard the clip. Recording stops when you leave the app; return to save or cancel it. Each clip can be up to five minutes, depending on the tool's remaining audio storage. Doodad does not send recordings to a server or provide live microphone streams to tools. Edit shows stored audio size and clip count. Reset saved data clears recordings together with that tool's saved entries, photos, and videos.

How do I save videos?

Use a tool that follows Doodad's video-saving instructions. Choose or record a MOV or MP4 file up to 32 MiB. Doodad prepares a local MP4 copy up to 720p without original metadata. Saved clips can be up to five minutes and 20 MiB each, with 60 MiB or 20 videos per tool. Choosing a clip alone does not save it. The tool must save its reference too. Videos are included only when Include saved data is on; recipients need a version of Doodad with video storage. Reset clears the tool's copies, without changing your photo library.

What if camera or microphone access is denied?

Other features remain available. To change your choice, open iOS Settings and find Doodad's permissions. Camera access is needed when taking a photo or video; microphone access is needed for voice recordings or video sound. Choosing an existing photo does not need microphone access.

Why won't an online tool work?

Doodad runs self-contained HTML tools offline. External fonts, libraries, images, network requests, and website navigation are blocked. Keep everything the tool needs inside one HTML page.

How do tips work?

All features are free. Settings > Leave a tip offers optional one-time tips. Apple processes payment. Tips unlock nothing and are not subscriptions. If the App Store is unavailable, you can keep using every feature. For purchase and refund help, use Apple's purchase support.

What should I include in a support message?

Tell us what happened, your device and iOS version, Doodad's version and build from Settings, and the steps that reproduce it. Share tool source or saved data only if you choose to include it.
